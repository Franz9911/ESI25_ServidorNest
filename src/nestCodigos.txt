//lista de estados en HttpException
400:BadRequest «Mala petición». El servidor no puede devolver una respuesta debido a un error del cliente. 
  Vea nuestra guía para resolver este error.
401 UnauthorizedException :«Se requiere autorización». Esto es devuelto por el servidor 
  cuando el recurso de destino carece de credenciales de autenticación válidas. 
404 Not Found: No se encontró el recurso solicitado». Este es el mensaje de 
  error más común de todos ellos. Este código significa que el recurso solicitado no existe, y el servidor no sabe si alguna vez existió
409 Conflict: Indica que la solicitud no pudo ser procesada debido a un conflicto con el
  estado actual del recurso que esta identifica. Esto ocurre a veces debido a múltiples ediciones simultáneas.
413 Request Entity Too Large
  La petición del navegador es demasiado grande y por ese motivo el servidor no la procesa.
415 Unsupported Media Type
  La petición del navegador tiene un formato que no entiende el servidor y por eso no se procesa.
422 Unprocessable Entity (WebDAV - RFC 4918)
  La solicitud está bien formada pero fue imposible seguirla debido a errores semánticos.
